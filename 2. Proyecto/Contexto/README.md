## Lo que se quedó en el repo del área, y por qué

No todo lo que toca este proyecto es de este proyecto:

- **`DECISIONS.md`** — es la bitácora del **área**, append-only y cronológica. Las decisiones sobre Renovare las tomó el área; partirla rompería la trazabilidad.
- **`contexto/13-convencion-naming.md`** y **`contexto/12-referencia-supernova.md`** — describen **capacidad reutilizable**, no este proyecto. La convención de nombres y el mapa de Supernova sirven a cualquier sistema que el área construya después.
- **`contexto/14-organizacion-proyectos.md`** — el modelo IPO aplica a **todos** los proyectos del área.
- **`contexto/99-pendientes.md`** — contradicciones abiertas del área.

**La frontera:** *si sobrevive al cierre del proyecto y sirve al siguiente, es del área. Si muere con el proyecto, es del proyecto.*
